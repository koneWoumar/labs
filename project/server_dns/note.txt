** domaine = nom essentiellement
** zone = ensemble d'enregistrement dns d'un domaine et enventuellement de ses sous-domaine (un fichier de configuration)
** serveurs DNS = serveurs qui diffusent les enregistrement des zones (sur lequel est deployer le fichier de configuration de la zone)

lorsqu'on achete un domaine,  par exemple allow.com :

- dans  le registre du TLP .com, on enregistre le propriétaire et l'ensemble des serveurs qui heberge la zone dedié au domaine.

lorsqu'on veut resoudre un dns d'un domaine :

- le client cherche le domaine dans le registre du TLP
- Si le domaine y existe, le client demande la liste des serveurs dns qui heberges la zone pointé par le domaine.
- Le client demande à ces serveurs dns de resoudre le dns . Si l'enregistrement existe dans la zone, les serveurs renvoie alors l'ip associé.
